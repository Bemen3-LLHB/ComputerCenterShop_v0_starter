# Validacio RA1 - ComputerCenterShop v0 starter

## Resultat

`ComputerCenterShop_v0_starter` queda declarat com a projecte inicial visible de l'alumnat per a RA1.

## Comprovacions realitzades

| Comprovacio | Resultat |
| --- | --- |
| Projecte inspeccionable a `fonts-i-projectes-base/` | Correcte |
| Separacio minima `model`, `view`, `main`, `dao`, `files` | Correcte |
| Dades inicials `users.txt` i `items.txt` | Correcte |
| Absencia de JDBC, SQL, ORM i dependències de base de dades | Correcte |
| POM sense dependències externes fora de RA1 | Correcte |
| Paquet preparat com a starter, no com a solucio completa | Correcte |
| Compilacio amb `javac` | Correcte, 17 fonts compilades |

## Rol docent

Aquest paquet no computa com a evidencia directa. Serveix com a punt de partida per resoldre el backlog i lliurar una evolucio pròpia del projecte.

## Validacio pendent d'entorn

La compilacio amb Maven depen de tenir `mvn` disponible al PATH de l'equip docent o de l'aula. En aquest entorn local `mvn` no esta disponible.
